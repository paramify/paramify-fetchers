# Azure category (fetchers/azure/*) — official azure-mgmt-* SDKs. Auth is the
# ambient credential chain via DefaultAzureCredential (service principal env,
# workload-identity federation, managed identity, or a cached `az login`); no
# secret is handed over and the `az` CLI is NOT required at runtime.
# azure-core / azure-mgmt-core arrive transitively.
#
# MAJORS ARE PINNED DELIBERATELY. Building this category turned up six breaking
# changes across azure-mgmt majors, every one of which produces wrong or empty
# evidence rather than an error:
#   - azure-mgmt-resource 26 dropped the root ResourceManagementClient re-export
#   - azure-mgmt-monitor 7 removed the diagnostic_settings operation group
#   - azure-mgmt-sql 4 renamed TDE `status` -> `state`
#   - azure-mgmt-postgresqlflexibleservers 2 dropped servers.list and renamed
#     the administrators operation group
#   - PolicyClient left azure-mgmt-resource for its own distribution
#   - azure-mgmt-keyvault 14 stopped flattening `properties`
# Upstream Prowler pins these exactly for the same reason. Patch releases stay
# open; majors are gated so a silent evidence regression cannot arrive by
# `pip install -U`.
